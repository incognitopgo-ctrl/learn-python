LEARN PYTHON IN 200 LINES - A COMPREHENSIVE GUIDE
==================================================

1. BASICS
---------
Python is a beginner-friendly language. Start by printing:
print("Hello, World!")

Variables store data:
name = "Alice"
age = 25
height = 5.9
is_student = True

2. DATA TYPES
-------------
int: whole numbers (42, -10, 0)
float: decimal numbers (3.14, -2.5)
str: text ("hello", 'world')
bool: True or False
list: ordered collection [1, 2, 3, "four"]
dict: key-value pairs {"name": "Bob", "age": 30}
tuple: immutable list (1, 2, 3)
set: unique values {1, 2, 3}

3. OPERATORS
------------
Arithmetic: + - * / // % **
Comparison: == != < > <= >=
Logical: and, or, not
Assignment: = += -= *= /=

4. STRING OPERATIONS
--------------------
Concatenation: "Hello" + " " + "World"
Repetition: "Ha" * 3 = "HaHaHa"
Indexing: text[0] gets first character
Slicing: text[1:4] gets characters 1-3
Methods: .upper(), .lower(), .strip(), .split(), .replace()
Formatting: f"My name is {name}"

5. LISTS
--------
Create: my_list = [1, 2, 3, 4]
Access: my_list[0] = 1
Append: my_list.append(5)
Remove: my_list.remove(3)
Length: len(my_list)
Slicing: my_list[1:3]
Sort: my_list.sort()
Reverse: my_list.reverse()

6. DICTIONARIES
---------------
Create: person = {"name": "John", "age": 30}
Access: person["name"] = "John"
Add: person["email"] = "john@example.com"
Delete: del person["age"]
Keys: person.keys()
Values: person.values()
Items: person.items()

7. CONTROL FLOW
---------------
If/Else:
if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teen")
else:
    print("Child")

8. LOOPS
--------
For loop - iterate over items:
for i in range(5):
    print(i)  # prints 0, 1, 2, 3, 4

for item in [1, 2, 3]:
    print(item)

While loop - repeat while condition is true:
count = 0
while count < 5:
    print(count)
    count += 1

Break and Continue:
for i in range(10):
    if i == 5:
        break  # exits loop
    if i == 2:
        continue  # skips rest of iteration
    print(i)

9. FUNCTIONS
------------
Define a function:
def greet(name):
    return f"Hello, {name}!"

result = greet("Alice")

Multiple parameters:
def add(a, b):
    return a + b

Default parameters:
def introduce(name, age=18):
    print(f"{name} is {age}")

10. LISTS COMPREHENSION
-----------------------
Create list with one line:
squares = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]

11. ERROR HANDLING
------------------
Try/Except:
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")
except Exception as e:
    print(f"Error: {e}")
finally:
    print("This always runs")

12. FILE OPERATIONS
-------------------
Read file:
with open("file.txt", "r") as file:
    content = file.read()

Write file:
with open("file.txt", "w") as file:
    file.write("Hello, World!")

Append to file:
with open("file.txt", "a") as file:
    file.write("\nNew line")

from datetime import datetime

import random
random_num = random.randint(1, 10)

14. CLASSES AND OBJECTS
------------------------
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def bark(self):
        return f"{self.name} says Woof!"

my_dog = Dog("Buddy", 3)
print(my_dog.bark())
